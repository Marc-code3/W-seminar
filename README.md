# Wer überlebte die Titanic?

Code zur Seminararbeit "Wer überlebte die Titanic? Was man mit KI-Programmierung aus historischen Daten erfährt" (W-Seminar KI, Pestalozzi-Gymnasium München).

## Inhalt

- `JupyterNotebook.ipynb`: Code der Arbeit (Datenaufbereitung, Modellvergleich, Kreuzvalidierung, GridSearchCV, finale Abgabe)
- `train.csv`, `test.csv`: Datensatz aus dem Kaggle-Wettbewerb "Titanic - Machine Learning from Disaster"

## Umgebung

- Python 3.13.16
- pandas 3.0.6
- scikit-learn 1.9.1
- matplotlib 3.11.2

Das Notebook wurde in Visual Studio Code geschrieben.
